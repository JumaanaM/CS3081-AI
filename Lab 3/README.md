CS3081 Artificial Intelligence - Lab 3: Propositional Logic & Model Checking

Overview
- This lab explores propositional logic and model checking in Python by encoding logical statements into a Knowledge Base (KB) to solve several puzzles. Using the `model_check` inference engine (`logic.py`), the program evaluates possible truth assignments to deduce the true identity of each character across multiple puzzles.

How to Run knights.py:
- Ensure the logic.py file is in the same directory as the knights.py file
- Run python knights.py in a new terminal
